# Garena Game Jam
 
Unity 2021.3.10f1
itch.io: https://dhyox.itch.io/qaja

(programmer notes ('25))
We developed this for the 2-days offline game jam by Garena.

For this project I implemented SRP of SOLID principle.
For optimization: used Comparetag for comparing collider. 
For game programming pattern: I used singleton for managers and state pattern for the game state control. 
For design pattern: I still only used model view pattern.

My friend helped a bit on making sure the player can feel the jump and stomp mechanic.
Not just endless platformer with jump and stomp mechanic, there's also enemy where the player can kill using stomp. 


For the tools and frameworks outside normal framework from unity, we used: Cinemachine
